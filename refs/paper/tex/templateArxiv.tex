\begin{abstract}
We study low-rank random feature models (RF-LR), an architecture where only the linear outputs \( A^{(\ell)} \) are trained while the input weights \( w^{(\ell)} \) are frozen at random. This factorization drastically reduces the parameter budget and exhibits dictionary/wavelet-like feature learning. We derive the NTK recursion for this architecture, analyze finite-width corrections with rank \( r \) bottlenecks, and explain low-to-high frequency learning via kernel gradient flow in Fourier space. Numerical experiments reveal stepwise loss curves and high-frequency spike formation with depth directly correlating to maximal learned frequency. We formalize the simplified model without bias scaling, develop NTK-based predictions, and explain how rank \( r \) bottlenecks yield \( O(1/r) \) kernel fluctuation decay and improved preconditioning.
\end{abstract}
