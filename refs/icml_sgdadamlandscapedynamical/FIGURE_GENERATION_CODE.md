# Python Code for Generating Figures in tofill.tex

This document compiles all Python code used to generate figures for the ICML paper `tofill.tex`.

## Figure Mapping

### 1. `trajectory_max_ratio.png` (Figure 5)
**File**: `experiments/table/logratio/track_logratio_during_training.py`

**Purpose**: Tracks log ratios $R_{i,j} = \log|f_i| - \log|f_j|$ during training at $x=0$ and plots the trajectory of $\max_{i,j} R_{i,j}(x=0)$ vs epoch.

**Key Functions**:
- `get_partial_fk_layer2()`: Computes layer-2 partial functions $f_k$ at a given $x$ location
- `compute_log_ratio_matrix()`: Computes the log-ratio matrix $R_{i,j}$
- `run_training_with_logratio_tracking()`: Main training loop that tracks log ratios at checkpoints

**Configuration** (from paper Table 2):
- 3 layers, $n=1024$, $r=15$, $\cos(8\pi x)$, 5k samples, 10k epochs, batch 160, SGD lr 0.01

---

### 2. `logratio_statistics_x0.png` (Figure 6 - heatmap)
**File**: `experiments/table/plot_layer2_logratios.py`

**Purpose**: Plots statistics (histogram) of log ratios $R_{i,j}$ at $x=0$ over all channel pairs.

**Key Functions**:
- `plot_log_ratio_statistics()`: Creates histogram of log ratios with statistics text

**Note**: The paper refers to this as a "heatmap" but it's actually a histogram distribution plot.

---

### 3. `four_setups_loss_with_lr_bars.png` (Figure 2)
**File**: `experiments/table/rerun_four_setups.py`

**Purpose**: Compares low-rank ($r=10$) vs full-rank ($r=1024$) training loss curves with different momentum values, showing learning rate reduction bars.

**Key Functions**:
- `train_one()`: Trains one configuration (low-rank or full-rank)
- `main()`: Trains 4 low-rank setups (momentum 0.0, 0.3, 0.6, 0.7) and plots them together
- `run_fullrank()`: Trains full-rank baseline
- `plot_only()`: Regenerates plot from existing JSON files

**Configuration**:
- Low-rank: factor=1, rank=10, n_train=5000, batch=4, 250 epochs, SGD lr=0.01, AdaptiveStagnation
- Full-rank: same but rank=1024, 1000 epochs

---

### 4. `channel_partials_layer5.png`, `channel_partials_layer16.png` (Figure 9)
**File**: `experiments/table/plot_frequency_partials.py`

**Purpose**: Plots partial layer functions (components 1 and 2) for each layer, showing channel specialization and frequency separation.

**Key Functions**:
- `plot_partials_for_config()`: Loads model, computes layer outputs, and plots partial functions for one configuration
- `load_model_state()`: Loads model from `model_parameters.pth` or `checkpoint.pth`

**Configuration** (from paper Table 2):
- Layer 5: 8 layers, $n=1024$, $r=15$, target $(144,48)$, 4k samples, 10k epochs, batch 100, Adam lr 0.001, fixWb=True
- Layer 16: same configuration

---

### 5. `spike_in_H_layer9.png` (Figure 9)
**File**: `experiments/table/plot_frequency_partials.py` (same script as above)

**Purpose**: Shows spike-like, spatially localized features in the pre-activation $H_k$ at layer 9.

**Note**: This is generated by the same script as channel_partials, but for a different layer (layer 9, which corresponds to the output after ReLU activation at layer 8).

---

### 6. `mlp_asymmetry_layer7.png`, `mlp_asymmetry_layer16.png` (Figure 10)
**File**: `experiments/table/plot_frequency_partials.py` (same script as above)

**Purpose**: Shows asymmetry when random features are trainable (fixWb=False), demonstrating loss of symmetry preservation.

**Configuration** (from paper Table 2):
- 8 layers, $n=1024$, $r=20$, target $(144,48)$, 4k samples, 10k epochs, batch 100, Adam lr 0.001, fixWb=False

---

### 7. `final_prediction.png` (Figure 8)
**Files**: Multiple scripts generate this:
- `experiments/table/train_frequency_layer_scaling.py`
- `experiments/table/train_frequency_layer_scaling_extended.py`
- `experiments/table/train_multi_frequency_benchmark.py`
- `experiments/table/test_frequency_benchmark.py`

**Purpose**: Shows final prediction vs target function $f(x)=\cos(36\pi x^2)-0.8\cos(12\pi x^2)$.

**Configuration** (from paper Table 2):
- 4 layers, $n=1024$, $r=50$, $N=1000$, RF-LR

---

### 8. `meanfield_density_epoch0.png`, `meanfield_density_epoch50.png` (Figure 11)
**File**: `experiments/table/meanfield_analysis/train_meanfield_weights.py`

**Purpose**: Generates mean-field weight distribution plots (histograms) for different epochs, showing the evolution of weight distributions through training.

**Key Functions**:
- `plot_meanfield_density()`: Creates histogram of weight distribution for a given epoch
- `train_one_config()`: Trains model and saves weights for each epoch, then generates density plots

**Configuration** (from script comments):
- factor=4 (cos(8πx)), rank=50, momentum=0.0
- factor=4 (cos(8πx)), rank=50, momentum=0.3
- factor=4 (cos(8πx)), rank=15, momentum=0.0

**Output**: PNG files for key epochs (0, 50, 100, 150, 200, 250) and a GIF showing evolution.

## Additional Supporting Scripts

### `experiments/table/plot_layer1_layer2_logratios_improved.py`
Plots log ratios for both layer 1 and layer 2, with improved visualization.

### `experiments/table/compute_layer1_layer2_logratios.py`
Computes log ratios for layer 1 and layer 2 at different $x$ values.

Mean-field analysis for the two-sided step toy model, showing channel specialization.

## Common Dependencies

All scripts use:
- `torch` and `torch.nn` for neural network training
- `matplotlib` for plotting (configured for LaTeX-style output)
- `numpy` for numerical operations
- `experiments.table.mmnn_vs.MMNN` - the low-rank neural network model class

## Matplotlib Configuration

Most scripts use LaTeX-style plotting with:
```python
plt.rcParams['figure.figsize'] = [12, 10]
plt.rcParams['font.size'] = 18
mpl.rcParams['mathtext.fontset'] = 'cm'
mpl.rcParams['savefig.dpi'] = 300
mpl.rcParams['font.family'] = 'STIXGeneral'
```

## Usage Examples

### Generate trajectory_max_ratio.png:
```bash
cd experiments/table/logratio
python track_logratio_during_training.py --config config_fig5_paper.json --out-dir runs/fig5_10k_epochs
```

### Generate logratio_statistics_x0.png:
```bash
cd experiments/table
python plot_layer2_logratios.py
```

### Generate four_setups_loss_with_lr_bars.png:
```bash
cd experiments/table
python rerun_four_setups.py  # trains and plots
# or
python rerun_four_setups.py --plot-only  # just regenerates plot from JSON
python rerun_four_setups.py --full-rank  # adds full-rank baseline
```

### Generate channel_partials and spike_in_H:
```bash
cd experiments/table
python plot_frequency_partials.py
```

### Generate meanfield_density plots:
```bash
cd experiments/table/meanfield_analysis
python train_meanfield_weights.py
```

## Notes

1. **Figure 1 (Architecture)**: This is a TikZ figure defined directly in the LaTeX file, not generated by Python.

2. **Figure 3 (Channel Specialization)**: This is also a TikZ figure in the LaTeX file.

3. **Figure 4 (Two-sided Step)**: TikZ figure in LaTeX.

4. **Log-ratio heatmap**: The paper refers to `logratio_statistics_x0.png` as a "heatmap" but it's actually a histogram. The script `plot_layer2_logratios.py` has a `plot_log_ratio_heatmap()` function that creates an actual heatmap, but the paper uses the statistics/histogram version.

5. **Model State**: Many scripts require saved model checkpoints (`model_parameters.pth` or `checkpoint.pth`) from training runs. These are typically generated by training scripts in `experiments/table/experiments/table/results_*` directories.
