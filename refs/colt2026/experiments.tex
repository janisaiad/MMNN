\section{Experiments}\label{sec:experiments}

This section presents numerical illustrations. All scripts are headless (matplotlib ``Agg'' backend). Setup: finite-width NTK scripts use a \textbf{3-layer (2 ReLU)} RF-LR architecture with hidden width 12000--20000 so that finite-width variance is small; deterministic proxy scripts iterate the recursion to large \(k\) (e.g.\ \(k_{\max}=4000\) or \(L=200\)). Bottleneck rank \(r\) is swept as indicated; \(n\) is the number of inputs, \(d\) the input dimension. Scripts in the first subsection are \textbf{deterministic}; the rest are \textbf{finite-width Monte Carlo} (they illustrate fluctuation scales and do not constitute proofs).

\subsection{Correlation alignment and equicorrelated spectrum (Theorem~\ref{thm:rflr-depth-scaling-mean}, Corollary~\ref{cor:conditioning-equicorrelated-highdim})}

\subsection{RKHS Puiseux exponent vs depth (Corollary~\ref{thm:no_rkhs_advantage}, extension to \(L\ge 4\))}

For zonal kernels on the sphere, the RKHS is controlled by the Puiseux exponent \(\gamma\) at the endpoint \(\rho=1\): if \(K(1-t)-K(1)\sim c\cdot t^\gamma\) for small \(t\), then \(\gamma\) determines the RKHS~\cite{bietti2021deepequalsshallowrelu}. The paper proves \(\gamma=1/2\) for the mean three-layer RF-LR kernel (same as shallow ReLU); extension to \(L\ge 4\) is open. We estimate \(\gamma(L)\) for the deterministic proxy \(\Theta^{(L)}(\rho)\) via log--log regression of the gap \(\Theta^{(L)}(1)-\Theta^{(L)}(1-t)\) vs \(t\). For \(L\in\{2,3,4,5,6\}\) we obtain \(\gamma(L)\approx 0.52\)--\(0.55\) with \(R^2>0.999\), suggesting the proxy's endpoint behavior is consistent with RKHS equivalence extending to \(L\ge 4\).

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.72\textwidth]{rkhs_puiseux_exponent_vs_depth}
  \caption{RKHS Puiseux exponent vs depth. Left: estimated \(\gamma(L)\) vs \(L\); reference \(\gamma=1/2\) (ReLU RKHS). Right: log--log gap vs \(t\) for \(L=2\) and \(L=6\). The proxy kernel exhibits \(\gamma\approx 1/2\) for \(L\ge 2\), consistent with RKHS equivalence extending beyond three layers.}
  \label{fig:rkhs_puiseux_depth}
\end{figure}
